Este material tem como finalidade introduzir os conceitos básicos de **Lógica de Programação**, desenvolvendo a capacidade de analisar problemas e construir soluções passo a passo.

Durante as atividades, o foco será:

* compreender o problema proposto
* organizar a solução em forma de **algoritmo**
* representar o algoritmo usando **fluxogramas**
* transformar o fluxograma em **código JavaScript**

A proposta é priorizar o raciocínio lógico antes da programação, utilizando o fluxograma como ferramenta de planejamento. Dessa forma, o aluno aprende a estruturar corretamente a solução antes de escrever o código.

Ao final das atividades, espera-se que o aluno seja capaz de:

* interpretar problemas simples
* montar fluxogramas corretos
* implementar a solução em JavaScript

O aprendizado será baseado principalmente na **prática com exercícios**, pois a lógica de programação se desenvolve por meio da resolução contínua de problemas.
